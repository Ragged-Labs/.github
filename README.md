# RaggedLabs Media

RaggedLabs Media develops practical software and intelligent tools that simplify everyday digital tasks, from media organisation to workflow automation.

We combine a rough, ragged visual style with carefully engineered software and AI-assisted development.

This repository contains our [public organisation profile](profile/README.md).

## Computational bioscience research

RaggedLabs Media is developing research software for traceable evidence datasets, reproducible analysis and review of infection-prevention research. We are seeking scientific collaboration for this workstream alongside our existing software products. See the [public profile](profile/README.md#computational-bioscience-research) for the current scope.
